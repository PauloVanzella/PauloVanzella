I like the spaces between things.

I’m interested in the point where different fields stop looking separate.

Code is one of the ways I explore that — but so are design, languages, chess, visual thinking and research. I like following a question far enough that it forces me to learn something I did not expect to learn.

I care less about fitting everything into one title and more about understanding how things connect: how a system is structured, how an interface feels, how a strategy emerges, or how a language changes the way an idea can be expressed.
